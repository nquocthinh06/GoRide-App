# Firebase setup

1. Tạo Firebase project riêng cho GoRide.
2. Đăng ký Android app bằng đúng applicationId.
3. Cấu hình FlutterFire CLI (`flutterfire configure`) ở máy phát triển.
4. Bật Authentication provider cần dùng.
5. Tạo Firestore và Realtime Database.
6. Deploy Rules sau khi review.
7. Cấu hình FCM và Google Maps API key theo từng môi trường.

Không commit service account JSON, private key hoặc API key có quyền rộng.
